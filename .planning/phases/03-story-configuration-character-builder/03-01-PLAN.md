<objective>
Build the Phase 3 character builder and story configuration form: responsive client components for 8 genre chips, up to 5 dynamic character rows, an optional premise, a primary Generate Story button, and a Surprise Me button. Wire submission to the Phase 1 streaming route through a reusable hook and expose streamed text plus loading/error states for Phase 4. Add Vitest interaction tests and verify with npm test, npx tsc --noEmit, and npm run build.
</objective>

<interfaces>
From `src/types/story.ts` (do not redefine):
```ts
export interface Character { id: string; name: string; role?: string }
export type Genre = 'Fantasy' | 'Sci-Fi' | 'Horror' | 'Romance' | 'Mystery' | 'Adventure' | 'Comedy' | 'Thriller';
export interface StoryRequest { characters?: Character[]; genre?: Genre | string; premise?: string; isSurprise?: boolean }
export interface ApiErrorResponse { error: string; code: 'MISSING_API_KEY' | 'RATE_LIMIT_EXHAUSTED' | 'GENERATION_ERROR' }
```
API contract: `POST /api/generate` accepts a JSON `StoryRequest` and returns `text/plain` streamed chunks. A 429 JSON body uses `ApiErrorResponse`.
Length limits mirror `src/lib/prompts.ts`: name 50, role 100, premise 500, maximum 5 characters.
</interfaces>
